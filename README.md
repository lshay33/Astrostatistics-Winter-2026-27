# Astroinformatics-Astrostatistics-Winter-2026-27

### What is this repository about and its main scientific goal?
This repository is to document the labs for Astrostatistics. The main goal of this class is to "introduce you to research with large survey data, teach you how to think about such data sets, and provide an overview of what is or soon will be available."

### What data is being used and where do they come from?
We will use data from the Pantheon+ and MUSH0ES databases. These databases contain datasets from various telescopes and missions, offering a wide-range of parameters.
